# Insurance Risk Analytics & Predictive Modeling

## Project Overview

This project analyzes historical insurance claims data for AlphaCare Insurance Solutions (ACIS) to identify insurance risk patterns, evaluate profitability, and support data-driven pricing strategies.

---

## Project Objectives

- Perform Exploratory Data Analysis (EDA)
- Analyze insurance risk metrics
- Identify geographic and vehicle risk patterns
- Implement reproducible data workflows using DVC
- Prepare for predictive modeling and premium optimization
